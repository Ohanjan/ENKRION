Privacy

Built to earn trust.

This page describes the privacy direction for the ORIN concept. It will be replaced with a complete policy before public release.

Current project status

ORIN is an early-stage concept and alpha project. This website does not currently provide user accounts, payments, or a downloadable application.

Website data

The website does not intentionally request personal data through an embedded form. If you contact the project by email, the information you send is used only to respond to your message and evaluate alpha interest.

Theme preference

Your light or dark appearance choice is stored locally in your browser. It is not transmitted to ORIN by this website.

Future product principles

  • Ask clearly before accessing files, applications, microphones, or connected devices.
  • Make consequential actions visible and reviewable.
  • Collect only the information required to provide the requested feature.
  • Provide understandable controls for history, permissions, and deletion.

Changes

This notice will change as ORIN gains real services. A dated, legally reviewed policy will be published before public data processing begins.
